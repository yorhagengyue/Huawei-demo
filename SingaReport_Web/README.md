## 数据流与同步特性

本应用实现了改进的数据流和同步机制，具有以下特点：

### 实时数据同步

- **即时反馈**: 报告提交后立即在 Dashboard 上可见，无需刷新页面
- **临时存储**: 使用浏览器本地存储临时保存新提交的报告，确保即使在离线状态下也能显示
- **定期自动刷新**: Dashboard 每 30 秒自动从服务器获取最新数据
- **手动刷新**: 用户可随时点击刷新按钮获取最新数据

### 数据源指示器

- **视觉指示**: 清晰显示当前数据来源（数据库或演示数据）
- **时间戳**: 显示上次更新时间，帮助用户了解数据新鲜度
- **不同状态标识**: 为不同数据源使用不同颜色和图标，提高可辨识度

### 开发与部署环境支持

- **演示模式**: 通过环境变量 `NEXT_PUBLIC_DEMO_MODE` 控制演示模式
- **平滑回退**: 当数据库连接失败时，开发环境自动回退到演示数据
- **错误处理**: 完善的错误处理和状态反馈机制

这些功能确保用户始终能看到最新报告，并清楚了解数据来源，提升整体用户体验。
